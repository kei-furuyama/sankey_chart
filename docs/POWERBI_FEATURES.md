# Power BI Sankey Chart - 書式設定ガイド

Power BI Desktop の書式設定パネル（Format pane）から操作できる設定項目の一覧です。

---

## データフィールド

| フィールド | 種類 | 説明 |
|-----------|------|------|
| **Source** | Grouping | フローの起点ノード名 |
| **Target** | Grouping | フローの終点ノード名 |
| **Value** | Measure | フローの数量） |

---

## Nodes（ノード設定）

| 設定項目 | 説明 | 範囲 | デフォルト |
|---------|------|------|-----------|
| **Node Width** | ノード（棒）の横幅（px） | 5〜100 | 24 |
| **Node Padding** | ノード間の縦方向の間隔（px） | 0〜100 | 16 |
| **Layout Iterations** | レイアウト反復回数（大きいほど交差が減るが描画が重くなる） | 1〜32 | 6 |
| **Color Mode** | ノードの色の決定方法 | Category Colors / Single Color | Category Colors |
| **Default Color** | Single Color モード時の色 | カラーピッカー | #1f77b4 |

### Color Mode の動作

- **Category Colors**: Power BI のテーマカラーパレットからノードごとに自動配色。個別の色変更も可能（後述の Node Colors カードから）。
- **Single Color**: 全ノードを同一色で表示。Default Color で指定した色が使用される。

---

## Node Colors（ノード個別色）

Category Colors モード時に表示されるカードです。各ノードの色を個別に変更できます。

- Power BI のテーマカラーに連動しており、テーマ変更時に自動で更新されます。
- 個別に変更した色はレポートに保存されます。

---

## Links（リンク設定）

| 設定項目 | 説明 | 選択肢 | デフォルト |
|---------|------|--------|-----------|
| **Color Mode** | リンク（フロー帯）の色の決定方法 | Source / Target / Gradient / Fixed | Source |
| **Opacity (%)** | リンクの透明度 | 0〜100 | 50 |
| **Link Sort** | リンクの並び順 | 下記参照 | Ascending |

### Color Mode の動作

| 選択肢 | 動作 |
|--------|------|
| **Source** | リンクの起点ノードの色で塗る |
| **Target** | リンクの終点ノードの色で塗る |
| **Gradient** | 起点ノードの色から終点ノードの色へグラデーション表示 |
| **Fixed** | 全リンクをグレー (#aaa) で統一表示 |

### Link Sort の動作

| 選択肢 | 動作 |
|--------|------|
| **Ascending (minimize crossing)** | d3-sankey の内部アルゴリズムでリンク交差を最小化 |
| **Descending** | 値の大きいフローを上に配置 |
| **By Value (small to large)** | 値の小さいフローを上に配置 |
| **By Value (large to small)** | 値の大きいフローを上に配置 |
| **Input Order (data sort)** | Power BI のデータ並び順を維持 |
| **None** | ソートなし |

---

## Link Labels（リンクラベル）

ヘッダーのトグルで表示/非表示を切り替えます。

| 設定項目 | 説明 | 範囲 | デフォルト |
|---------|------|------|-----------|
| **Show** | リンク上に値ラベルを表示 | ON / OFF | OFF |
| **Font Size** | ラベルのフォントサイズ | 6〜24 | 10 |

- リンクの幅が8px未満の場合、ラベルは自動的に非表示になります。

---

## Node Labels（ノードラベル）

ヘッダーのトグルで表示/非表示を切り替えます。

| 設定項目 | 説明 | デフォルト |
|---------|------|-----------|
| **Show** | ノード名ラベルを表示 | ON |
| **Font** | フォントファミリー | Segoe UI |
| **Font Size** | フォントサイズ（6〜48） | 12 |
| **Color** | ラベルの文字色 | #333333 |

- ラベルはノードの位置に応じて自動的に左右に配置されます（チャート中央より左のノードは右側、右のノードは左側）。

---

## Node Data Labels（ノードデータラベル）

ノードの合計値を数値で表示します。ヘッダーのトグルで表示/非表示を切り替えます。

| 設定項目 | 説明 | デフォルト |
|---------|------|-----------|
| **Show** | データラベルを表示 | OFF |
| **Font** | フォントファミリー | Segoe UI |
| **Font Size** | フォントサイズ（6〜48） | 10 |
| **Color** | ラベルの文字色 | #666666 |

- Node Labels と同時に有効な場合、データラベルはノード名の下に表示されます。

---

## Margins（マージン設定）

チャート描画領域の余白を調整します。ラベルが切れる場合や、よりコンパクトに表示したい場合に使用します。

| 設定項目 | 説明 | 範囲 | デフォルト |
|---------|------|------|-----------|
| **Top** | 上マージン（px） | 0〜300 | 20 |
| **Right** | 右マージン（px） | 0〜300 | 120 |
| **Bottom** | 下マージン（px） | 0〜300 | 20 |
| **Left** | 左マージン（px） | 0〜300 | 120 |

- 左右のデフォルト値（120px）はノードラベルの表示領域を確保するための値です。ラベルを非表示にする場合は小さくしても問題ありません。
